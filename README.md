# AssetTrack

AssetTrack is an Office Asset and Inventory Management System developed as a full-stack web application.

# Technology Stack

- ReactJS
- Ant Design
- Node.js
- ExpressJS
- Microsoft SQL Server
- RESTful API
- Git and GitHub

# Planned Features

- User authentication
- Dashboard
- Asset management
- Category management
- CRUD operations
- Search and filtering
- Asset reports
- RESTful API
